# PAIRPLAY

안드로이드 자캐 오버레이 앱. 등록한 자캐가 다른 앱 위에 떠서 생활하고,
두 캐릭터가 관계와 성격에 따라 서로 반응한다.

## 설치 방법 (휴대폰만으로)

1. 이 저장소의 **Releases** 탭을 연다.
2. 가장 최신 릴리스의 `pairplay-build-N.apk` 를 누른다.
3. 다운로드가 끝나면 알림을 눌러 설치한다.
   - 처음이라면 "출처를 알 수 없는 앱 설치 허용"을 켜라고 안내가 뜬다. 허용한다.
   - Play 프로텍트 경고가 뜰 수 있다. 개인이 만든 앱이라 나오는 정상 경고다.
4. 앱을 열고 안내에 따라 권한을 허용한다.

업데이트할 때도 같은 방법으로 새 APK 를 설치하면 기존 앱 위에 덮어써진다.
캐릭터와 설정은 그대로 유지된다.

## 빌드 방법

빌드는 GitHub Actions 에서 자동으로 이루어진다. `main` 또는 `claude/**` 브랜치에
푸시하면 단위 테스트를 돌리고 릴리스 APK 를 만들어 Releases 에 올린다.

### 서명 키

모든 빌드가 같은 키로 서명되어야 기존 앱 위에 업데이트할 수 있다.
키는 저장소에 넣지 않고 GitHub Actions Secrets 에 보관한다.

| 시크릿 이름 | 내용 |
| --- | --- |
| `KEYSTORE_BASE64` | 키스토어 파일을 Base64 로 인코딩한 한 줄 문자열 |
| `KEYSTORE_PASSWORD` | 키스토어 비밀번호 |
| `KEY_ALIAS` | 키 별칭 |
| `KEY_PASSWORD` | 키 비밀번호 |

시크릿이 없으면 debug 키로 서명된 임시 APK 가 만들어진다.
**키를 잃어버리면 기존 앱 위에 업데이트할 수 없으니 따로 백업해 둘 것.**
