# PAIRPLAY

안드로이드 자캐 오버레이 앱. 등록한 자캐가 다른 앱 위에 떠서 생활하고,
두 캐릭터가 관계와 성격에 따라 서로 반응한다.

## 설치 방법 (휴대폰만으로)

1. 이 저장소의 **Releases** 탭을 연다.
2. 가장 최신 릴리스의 `pairplay-build-N.apk` 를 누른다.
3. 다운로드가 끝나면 알림을 눌러 설치한다.
   - 처음이라면 "출처를 알 수 없는 앱 설치 허용"을 켜라고 안내가 뜬다. 허용한다.
   - Play 프로텍트 경고가 뜰 수 있다. 개인이 만든 앱이라 나오는 정상 경고다.
4. 앱을 열고 안내에 따라 권한을 허용한다.

업데이트할 때도 같은 방법으로 새 APK 를 설치하면 기존 앱 위에 덮어써진다.
캐릭터와 설정은 그대로 유지된다.

## 빌드 방법

빌드는 GitHub Actions 에서 자동으로 이루어진다. `main` 또는 `claude/**` 브랜치에
푸시하면 단위 테스트를 돌리고 릴리스 APK 를 만들어 Releases 에 올린다.

### 서명 키

모든 빌드가 같은 키로 서명되어야 기존 앱 위에 업데이트할 수 있다.
키는 저장소에 넣지 않고 GitHub Actions Secrets 에 보관한다.

| 시크릿 이름 | 내용 |
| --- | --- |
| `KEYSTORE_BASE64` | 키스토어 파일을 Base64 로 인코딩한 한 줄 문자열 |
| `KEYSTORE_PASSWORD` | 키스토어 비밀번호 |
| `KEY_ALIAS` | 키 별칭 |
| `KEY_PASSWORD` | 키 비밀번호 |

시크릿이 없으면 debug 키로 서명된 임시 APK 가 만들어진다.
**키를 잃어버리면 기존 앱 위에 업데이트할 수 없으니 따로 백업해 둘 것.**

## 진행 상황

- [x] 프로젝트 구조, 데이터 모델, CI 빌드 파이프라인
- [x] 1차: 오버레이, 캐릭터 등록, 기본 애니메이션, 음악 재생 상태 반응, 온보딩/권한
- [ ] 2차: 관계 엔진, 상황극 스케줄러, 장면 편집기, 홈 위젯

1차는 **자동 테스트와 빌드까지만 통과한 상태**다. 실제 기기 검증은 아직 하지 않았다.

- [구현 현황](docs/구현-현황.md) — 구현한 것, 안 한 것, 안드로이드가 막고 있는 것
- [테스트 결과](docs/테스트-결과.md) — 자동으로 확인한 것과 기기에서 봐야 하는 것
- [설치와 업데이트](docs/설치와-업데이트.md) — 설치 방법, 데이터 보존, 서명 키

## 이 앱이 해 주지 못하는 것

안드로이드 제약이라 구현으로 풀 수 없는 부분이다. 미리 알아 두면 덜 당황스럽다.

- 비밀번호 입력 화면 같은 **민감한 화면을 자동으로 피하지 못한다.** 오버레이 앱은
  지금 화면이 무엇인지 알 수 없다. 대신 캐릭터를 길게 누르면 바로 숨겨진다.
- 은행 앱 등 일부 앱은 화면 위 오버레이를 강제로 숨긴다. 캐릭터가 사라지는 건 정상이다.
- 휴대폰을 재부팅한 뒤에는 앱을 열어 직접 시작해야 한다. 안드로이드 15부터 이런
  종류의 서비스는 부팅 직후 자동 시작이 막혔다.
- 캐릭터가 떠 있는 동안 상시 알림이 함께 표시된다. 끌 수 없다.
