# 테스트 결과

정직하게 구분해서 적는다. **실제 기기에서 확인한 항목은 아직 없다.**
여기 적힌 것은 GitHub Actions 에서 자동으로 돌린 것뿐이다.

## 자동으로 확인한 것

매 푸시마다 GitHub Actions 에서 아래를 돌린다. 하나라도 실패하면 APK 가 나오지 않는다.

| 단계 | 내용 |
| --- | --- |
| 컴파일 | Kotlin / Compose / Room(KSP) 전체 빌드 |
| 단위 테스트 | 아래 68개 |
| Lint | Android Lint 검사 |
| 릴리스 빌드 | 서명된 APK 생성 |
| 서명 검증 | apksigner 로 실제 APK 의 인증서 확인 |

### 단위 테스트 목록

**관계 타입 (2개)**
- 저장된 값이 깨져 있어도 기본값으로 떨어진다
- 방향 지정이 필요한 관계는 짝사랑뿐이다

**자세 계산 (6개)** — 캐릭터가 이상하게 찌그러지거나 잘리지 않는지
- 점프가 시작과 끝에서 바닥에 붙고 중간에 가장 높다
- 진행도가 범위를 벗어나도 안전하게 잘린다
- 17가지 동작 전부가 약속한 변형 범위 안에 있다
- 이동 동작만 창을 옮긴다
- 가만히 있는 동작은 반복 동작으로 표시된다
- 매달린 자세도 창 여백 약속을 넘지 않는다

**창 여백 (3개)** — 캐릭터가 창 밖으로 잘려 나가지 않는지
- 실제 그리기와 같은 계산으로 네 모서리를 돌려 8가지 캐릭터 비율에서 확인
- 크기가 0 이어도 터지지 않는다
- 여백이 캐릭터보다 커지지 않는다 (터치를 가로채는 면적이므로)

**표시 효과 (9개)** — 하트·느낌표가 제대로 뜨고 사라지는지
- 띄우기 전에는 아무것도 그리지 않는다 / 시간이 지나며 위로 올라간다
- 수명이 끝나면 저절로 사라진다 / 아무리 많이 띄워도 개수가 제한된다
- 그릴 값들이 화면 밖으로 튀지 않는다
- 크기가 그리기 쪽 약속(창 여백 계산의 근거)을 넘지 않는다
- **땀과 핏대는 머리 위 허공이 아니라 캐릭터 그림 위에 붙어 있는다** (😓 처럼)
- 하트·느낌표·음표는 떠오른다
- 지우면 즉시 비워진다

**기분 기호 (6개)** — 지금 기분을 알리는 기호가 적당히 나오는지
- 짧고 분명한 순간(놀람·쓰다듬기·수줍음·노려보기·장난·졸기)에는 기호가 붙는다
- 자주 일어나는 동작(걷기·쳐다보기 등)에는 붙지 않는다
- 부딪힘은 여기서 띄우지 않는다 (느낌표가 두 개씩 뜨던 문제)
- 함께하는 동작은 상황극 안에서만 알린다
- 기분이 동작과 맞는다 / 기호가 붙는 동작은 전체의 절반을 넘지 않는다

**내 행동에 반응 (8개)** — 흔들기·톡톡·충전기·이어폰·화면 돌리기·잠금 해제
- 모든 사건에 반응이 있다
- **흔들면 어지러워한다** (아주 팔팔한 아이는 금방 털고 일어난다)
- **뺏기면(충전기·이어폰 분리) 어리둥절이 아니라 아쉬워한다**
- **반짝임(✨)은 번뜩이는 순간에만 쓴다** (신남은 꽃이 맡는다)
- 톡톡 두 번은 애정 표현이다 / 이어폰을 꽂으면 음악을 기대한다
- **금지한 동작은 어떤 사건에서도 나오지 않는다**
- 모든 동작을 막아 두어도 터지지 않는다

**상황극 스케줄러 (13개)** — 관계 엔진의 핵심
- **조는 시간이 전체의 15% 를 넘지 않는다** (길어서 실제 체감이 크던 문제)
- **졸고 나서 곧바로 또 졸지 않는다 / 놀란 직후에는 졸지 않는다**
- 장면의 마디가 순서대로 나온다
- 상대 마디를 기다리는 쪽은 짧게 기다린다
- 쿨다운 전에는 같은 장면이 다시 나오지 않는다
- **장면이 끝나지 않고 멈추는 일이 없다** (실제로 터졌던 버그의 재발 방지)
- 금지한 행동은 어떤 장면에도 나오지 않는다
- 한 명뿐이면 상대가 필요한 장면은 나오지 않는다
- 짝사랑은 마음을 품은 쪽이 몰래 본다 (방향을 바꾸면 역할도 뒤집힌다)
- 장면이 없으면 혼자 하는 동작을 돌려준다
- 붙잡으면 진행 중이던 장면을 버린다
- 관계를 바꾸면 장면 묶음도 바뀐다

**표정 (7개)** — 기분에 따라 그림을 갈아 끼우는 부분
- 동작마다 어울리는 표정이 정해져 있다
- 걷기·숨쉬기 같은 평범한 동작은 기본 얼굴로 둔다 (그림이 깜빡이지 않게)
- 모든 동작이 표정을 하나씩 갖는다
- 등록할 수 있는 표정 목록에 '기본'은 들어 있지 않다
- 표정 그림 목록을 저장하고 다시 읽는다 / 하나만 바꾸거나 지울 수 있다
- 저장된 값이 깨져 있어도 터지지 않는다

**이미지 축소 배율 (4개)** — 큰 이미지에서 메모리가 터지지 않는지

**투명 여백 잘라내기 (4개, 실제 비트맵 사용)** — 창이 쓸데없이 터치를 가로채지 않는지

## 개발 중 확인 방법

애니메이션·관계 엔진·스케줄러는 안드로이드에 기대지 않게 만들어서, 기기나 에뮬레이터
없이 순수 코틀린으로 컴파일해 바로 돌려볼 수 있다. 실제로 이 방식으로 스케줄러가
영원히 멈추는 버그를 CI 에 올리기 전에 찾아 고쳤다.

## 실제 기기에서만 확인할 수 있는 것

자동 테스트로는 확인이 불가능하다. 설치 후 직접 봐 주셔야 한다.

- [ ] 캐릭터가 다른 앱 위에 실제로 뜨는지
- [ ] **캐릭터 창 바깥에서 원래 앱이 정상적으로 눌리는지** (가장 중요)
- [ ] 캐릭터를 끌어서 옮기는 느낌이 자연스러운지
- [ ] 캐릭터를 톡 쳤을 때 반응하는지
- [ ] 길게 눌러 숨기기가 되는지
- [ ] 알림에서 숨기기·중지가 되는지
- [ ] 음악 앱을 틀었을 때 반응하는지 (앱마다 다를 수 있음)
- [ ] 화면 회전, 앱 전환, 화면 잠금 후에도 멀쩡한지
- [ ] 애니메이션이 배터리를 심하게 먹지 않는지
- [ ] 큰 이미지를 등록했을 때 느리거나 튕기지 않는지
- [ ] 캐릭터를 문지르면 따라 움직이지 않고 쓰다듬기가 되는지 (두 명 다)
- [ ] 손가락으로 집었을 때 대롱대롱 매달리는 게 보이는지
- [ ] 손으로 둘을 겹쳐 놓으려 해도 겹쳐지지 않고 밀리는지, 튕겨 나가는지
- [ ] 둘을 겹칠 때 화면이 튀지 않는지
- [ ] 위아래로 떨어뜨려 놔도 서로 만나러 가는지
- [ ] 홈 화면 위젯이 검은 상자가 아니라 제대로 보이는지
- [ ] 성격 수치를 양 끝으로 벌려 놓으면 둘의 행동이 달라 보이는지
- [ ] 표정 그림을 등록하면 기분에 맞춰 실제로 바뀌는지
- [ ] **숨기면 하트·느낌표까지 완전히 멈추는지** (그림만 감추고 뒤에서 움직이지 않는지)
- [ ] 한쪽을 옮겨서 놓았을 때 **다른 쪽이 제자리에 가만히 있는지**
- [ ] 놓는 순간 튀지 않는지
- [ ] 제자리에 서 있을 때 둘이 서로 마주 보는지
- [ ] 기본 그림 바꾸기가 되는지 (이름·크기·성격이 그대로 남는지)
- [ ] 캐릭터 수정 → '바라보는 방향'을 맞추면 둘이 실제로 마주 보는지
- [ ] 조는 동작이 예전보다 덜 나오는지
- [ ] 휴대폰을 흔들면 반응하는지
- [ ] 캐릭터를 톡톡 두 번 치면 한 번보다 크게 반응하는지
- [ ] 충전기·이어폰을 꽂고 뺄 때 반응하는지
- [ ] 잠금을 풀었을 때 반겨 주는지
- [ ] 캐릭터를 세게 뿌리면 날아갔다 떨어지는지
- [ ] 천천히 내려놓으면 그 자리에 그대로 서 있는지 (떨어지지 않는지)
- [ ] 화면을 돌릴 때 반응하는지
- [ ] 표정 그림을 등록하지 않은 캐릭터가 지금까지처럼 멀쩡한지

문제가 있으면 **어느 항목에서 어떻게 이상했는지**만 알려주시면 고칠 수 있다.

## 하지 않은 테스트

- **계측 테스트(에뮬레이터 실행)** — 오버레이 동작은 에뮬레이터에서도 실제 동작과
  차이가 커서, 통과해도 "기기에서 된다"는 보장이 되지 않는다. 잘못된 안심을 주느니
  하지 않고 위 확인 목록으로 남기는 쪽을 택했다.
- **여러 기기·제조사별 테스트** — 기기가 하나뿐이다. 제조사 스킨(삼성 One UI 등)이
  오버레이를 다루는 방식이 다를 수 있다.
