# 테스트 결과

정직하게 구분해서 적는다. **실제 기기에서 확인한 항목은 아직 없다.**
여기 적힌 것은 GitHub Actions 에서 자동으로 돌린 것뿐이다.

## 자동으로 확인한 것

매 푸시마다 GitHub Actions 에서 아래를 돌린다. 하나라도 실패하면 APK 가 나오지 않는다.

| 단계 | 내용 |
| --- | --- |
| 컴파일 | Kotlin / Compose / Room(KSP) 전체 빌드 |
| 단위 테스트 | 아래 14개 |
| Lint | Android Lint 검사 |
| 릴리스 빌드 | 서명된 APK 생성 |
| 서명 확인 | 릴리스 키로 서명되었는지 확인 |

### 단위 테스트 목록

**관계 타입 (2개)** — 2차 관계 엔진이 쓸 값들이 안전하게 동작하는지
- 저장된 값이 깨져 있어도 기본값으로 떨어진다
- 방향 지정이 필요한 관계는 짝사랑뿐이다

**자세 계산 (4개)** — 캐릭터가 이상하게 찌그러지거나 뒤집히지 않는지
- 점프가 시작과 끝에서 바닥에 붙고 중간에 가장 높다
- 진행도가 범위를 벗어나도 안전하게 잘린다
- 9가지 동작 전부가 말이 되는 배율·회전·이동 범위 안에 있다
- 이동 동작만 창을 옮긴다

**이미지 축소 배율 (4개)** — 큰 이미지에서 메모리가 터지지 않는지
- 작은 이미지는 줄이지 않는다
- 큰 이미지는 2의 거듭제곱으로 줄인다
- 줄인 뒤 크기가 한계 안에 들어온다
- 0이나 음수가 들어와도 안전하다

**투명 여백 잘라내기 (4개, 실제 비트맵 사용)** — 창이 쓸데없이 터치를 가로채지 않는지
- 가장자리 투명 여백을 정확히 잘라낸다
- 전부 투명한 이미지는 거부한다
- 잘라낼 것이 없으면 원본을 그대로 쓴다
- 거의 투명한 픽셀(알파 8 이하)은 여백으로 본다

## 실제 기기에서만 확인할 수 있는 것

자동 테스트로는 확인이 불가능하다. 설치 후 직접 봐 주셔야 한다.

- [ ] 캐릭터가 다른 앱 위에 실제로 뜨는지
- [ ] **캐릭터 창 바깥에서 원래 앱이 정상적으로 눌리는지** (가장 중요)
- [ ] 캐릭터를 끌어서 옮기는 느낌이 자연스러운지
- [ ] 캐릭터를 톡 쳤을 때 반응하는지
- [ ] 길게 눌러 숨기기가 되는지
- [ ] 알림에서 숨기기·중지가 되는지
- [ ] 음악 앱을 틀었을 때 반응하는지 (앱마다 다를 수 있음)
- [ ] 화면 회전, 앱 전환, 화면 잠금 후에도 멀쩡한지
- [ ] 애니메이션이 배터리를 심하게 먹지 않는지
- [ ] 큰 이미지를 등록했을 때 느리거나 튕기지 않는지

문제가 있으면 **어느 항목에서 어떻게 이상했는지**만 알려주시면 고칠 수 있다.

## 하지 않은 테스트

- **계측 테스트(에뮬레이터 실행)** — 오버레이 동작은 에뮬레이터에서도 실제 동작과
  차이가 커서, 통과해도 "기기에서 된다"는 보장이 되지 않는다. 잘못된 안심을 주느니
  하지 않고 위 확인 목록으로 남기는 쪽을 택했다.
- **여러 기기·제조사별 테스트** — 기기가 하나뿐이다. 제조사 스킨(삼성 One UI 등)이
  오버레이를 다루는 방식이 다를 수 있다.
