# 설치와 업데이트

## 처음 설치

1. 휴대폰 브라우저로 저장소의 **Releases** 탭을 연다.
2. 맨 위 릴리스의 `pairplay-build-N.apk` 를 누른다.
3. 다운로드가 끝나면 알림을 눌러 설치한다.

### 처음에만 나오는 안내 두 가지

- **"출처를 알 수 없는 앱 설치 허용"** — 브라우저나 파일 앱에 이 앱을 설치할 권한을
  주는 화면이다. 허용하면 된다.
- **Play 프로텍트 경고** — Play 스토어를 거치지 않은 앱이라 뜨는 경고다.
  "무시하고 설치"를 고르면 된다.

## 업데이트

새 APK 를 같은 방법으로 내려받아 설치하면 **기존 앱 위에 덮어써진다.**
지우고 다시 깔 필요가 없고, 등록한 캐릭터와 설정도 그대로 남는다.

이게 가능한 조건은 두 가지다.

1. `applicationId` 가 계속 `com.pairplay.app` 로 같을 것.
2. 모든 빌드가 **같은 서명 키**로 서명될 것.

두 가지 모두 저장소와 빌드 설정에 고정해 두었다.

## 데이터가 어디에 남는가

| 데이터 | 위치 |
| --- | --- |
| 캐릭터, 짝, 장면 | 앱 전용 데이터베이스 `pairplay.db` |
| 오버레이 설정 | DataStore |
| 캐릭터 이미지 | 앱 전용 저장소 `files/characters/` |

전부 앱 전용 영역이라 다른 앱이 볼 수 없다. 앱을 **삭제하면 함께 지워진다.**
덮어쓰기 업데이트에서는 지워지지 않는다.

Room 스키마가 바뀔 때 데이터를 버리는 방식(`fallbackToDestructiveMigration`)은
쓰지 않는다. 스키마가 바뀌면 마이그레이션을 따로 작성한다.

## 서명 키를 잃어버리면

같은 키로 서명할 수 없게 되어 **기존 앱 위에 업데이트할 수 없다.**
그때는 앱을 지우고 새로 설치해야 하고, 그 과정에서 캐릭터와 설정이 사라진다.

키는 GitHub Actions Secrets 네 개에 들어 있다.

- `KEYSTORE_BASE64`
- `KEYSTORE_PASSWORD`
- `KEY_ALIAS`
- `KEY_PASSWORD`

GitHub 에 저장된 시크릿은 **다시 꺼내 볼 수 없다.** 처음 받은 값을 따로 보관해 둘 것.
